# Octic Agent Pack

Built-in production-oriented roles:

- research — evidence-driven research and synthesis
- developer — software engineering, debugging and implementation
- data — structured-data analysis and validation
- workflow — multi-step planning, verification and release operations
- default — general assistance

The same role definitions are exposed by the API and the Gradio UI. API, UI and notebooks all exercise the same OcticAgent facade.

For live execution, configure a provider API key such as OPENAI_API_KEY and optionally OCTIC_AI_AGENT_MODEL.
