# Octic AI Agent Kaggle

Kaggle notebooks are kept under `kaggle/`.

- `octic_ai_agent_kaggle_smoke.ipynb` — install, import, package and API smoke test.
- `octic_ai_agent_agent_eval.ipynb` — multi-agent role evaluation with credential-gated live execution.

The notebooks never store API keys. Configure provider credentials through the Kaggle environment/secrets before enabling live runs.
