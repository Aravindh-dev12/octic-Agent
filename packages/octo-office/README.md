# Octo Office Dashboard

**2D Isometric Office Dashboard & Real-Time Multi-Agent Workflow Visualizer**

Octo Office provides an isometric virtual dashboard that renders multi-step agent delegation chains, desk activities, and token/cost savings metrics in real time.

---

## Key Features

- **Multi-Step Pipeline Visualizer**: Watch task delegation flow dynamically across agents in real time.
- **Activity Streams & Audit Logs**: Searchable, categorized logs recording tool executions and container events.
- **Cost & Token Analytics**: Telemetry calculating tokens spent, speedups, and estimated operational savings.
- **3D Mascot Tab**: Built-in tab rendering the WebGL 3D purple octopus mascot model.

---

## Quick Start

```bash
# Start the office dashboard development server (Port 4200)
pnpm dev

# Build for production
pnpm build
```

Open [http://localhost:4200](http://localhost:4200) to view the dashboard.
