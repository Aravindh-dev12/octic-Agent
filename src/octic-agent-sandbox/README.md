# Octic AI Agent Sandbox

Octic AI Agent supports optional isolated execution backends for workloads that need additional process or environment boundaries.

## Install

Install the sandbox integration with the main package:

    python -m pip install "octic-ai-agent[sandbox]"

For a smaller installation, choose a backend-specific extra when it matches your deployment:

    python -m pip install "octic-ai-agent[docker]"
    python -m pip install "octic-ai-agent[e2b]"
    python -m pip install "octic-ai-agent[modal]"
    python -m pip install "octic-ai-agent[daytona]"
    python -m pip install "octic-ai-agent[ssh]"

Some providers require their own account credentials, local runtimes, or system packages.

## Configuration guidance

- Use least-privilege filesystem access.
- Set explicit CPU, memory, and execution-time limits where supported.
- Disable network access for untrusted workloads unless it is required.
- Treat code generated by an AI agent as untrusted input.
- Keep sandbox credentials outside the repository.

## Development

The sandbox integration lives in this directory. Run its targeted tests from this component's environment and validate any provider-specific changes against the relevant backend.

Internal import and executable identifiers may differ from the Octic AI Agent brand for compatibility. Keep those identifiers stable unless a coordinated migration updates all dependent code, configuration, and documentation.
